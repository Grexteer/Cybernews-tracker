HttpOnly cookie check

This page just set two cookies:

  • js_visible_cookie - a normal cookie, readable by JavaScript
  • httponly_cookie - marked HttpOnly, hidden from JavaScript

Try it yourself

  1. Open the developer tools (F12) and switch to the Console tab.
  2. Type document.cookie and press Enter.
  3. Only js_visible_cookie shows up. httponly_cookie (and session_token if you are logged in) are missing.
  4. Now open Application → Cookies (Firefox: Storage): all cookies are there - the browser still sends them to the server, scripts just can't read them.

Why it matters: if an attacker injects a script (XSS), it can steal js_visible_cookie but not an HttpOnly session cookie.
